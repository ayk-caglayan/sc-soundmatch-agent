# A Class of Physical Modeling Recurrent Networks for Analysis/Synthesis of Plucked String Instruments (Su & Liang, TNN 2002)

**Authors:** Alvin W. Y. Su, Sheng-Fu Liang
**Venue:** IEEE Transactions on Neural Networks, Vol. 13, No. 5, 2002
**PDF:** SynthMatch-RNN-Strings-Alvin-TNN-2002.txt

## Summary

Early work using **recurrent neural networks** structurally inspired by physical models to synthesize plucked string instruments. Automatic parameter estimation via multi-stage training on recorded tones. Applied to guitar, harp, Chinese instruments (Chin, Yueh-chin, Pipa). Includes vibrato and portamento effects.

## Connections

- Very early neural approach to physical model parameter estimation
- Predates deep learning era; uses 2002-era RNNs
- Physical modeling synthesis later revisited with modern methods in [Han thesis](han-thesis-2025.md)
