# Empirical Physical Modeling for Bowed String Instruments (Sterling & Bocko, ICASSP 2010)

**Authors:** Mark Sterling, Mark Bocko
**Venue:** ICASSP 2010
**PDF:** SynthMatch-BowedString-ICASSP-2010.txt

## Summary

Assembles a complete empirical violin physical model: digital waveguide bowed string dynamics + experimentally measured bridge input admittance + monopole radiativity. Combines synthesis algorithms with acoustic measurements for realistic violin sound prediction. Notes that control parameter estimation is a challenging open problem due to nonlinearity.

## Connections

- Early physical modeling work; parameter estimation mentioned as future work
- Digital waveguide model from JOS's physical audio signal processing framework
