# wav2shape: Hearing the Shape of a Drum Machine (Han & Lostanlen, 2020)

**Authors:** Han Han, Vincent Lostanlen
**Year:** 2020 (arXiv 2007.10299v1)
**PDF:** SynthMatch-wav2shape-2007.10299v1.txt

## Summary

Recovers physical attributes (shape, material) from drum machine waveforms via time-frequency scattering analysis + supervised ML. An early work from the Han/Lostanlen collaboration that laid groundwork for the PNP loss and perceptual sound matching research. Uses functional transformation theory for dataset synthesis.
